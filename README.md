# СТАРТ

Адаптивное веб-приложение для первого месяца тренировок в спортзале.

## Возможности

- Три чередующиеся full-body тренировки и рекомендации по четырём неделям.
- Управляемая разминка с пятиминутным таймером кардио и спокойная заминка.
- Пошаговый экран занятия: вес, повторы или секунды, отметки подходов и таймер отдыха.
- Автоматическое сохранение этапа и незавершённой тренировки в `localStorage`.
- Дневник с историей, оценкой нагрузки, общим объёмом, графиком и экспортом JSON.
- Каталог упражнений с поиском, фильтрами и подсказками по технике.
- Офлайн-запуск ранее открытых экранов и установка на экран «Домой» после публикации по HTTPS.
- Мобильная и десктопная навигация, клавиатурные состояния и поддержка reduced motion.

Регистрации и сервера нет. Данные доступны только в текущем браузере; очистка данных браузера удалит их.

## GitHub и хостинг

Исходники: https://github.com/Kutyga/start-gym

После запуска workflow `Build and deploy to GitHub Pages` приложение публикуется на https://kutyga.github.io/start-gym/

Workflow запускается автоматически при изменении ветки `main` и вручную через Actions. Готовая конфигурация находится в `deploy-pages.yml`; для активации её нужно разместить в `.github/workflows/deploy-pages.yml`.

При чистой сборке иконки генерируются скриптом `scripts/generate-icons.py`, а фото упражнения загружается из Free Exercise DB.

## Запуск

```bash
npm install
npm run dev
```

Производственная сборка:

```bash
npm run build
npm run preview
```

## Технологии

React, TypeScript, Vite, Tailwind CSS, Radix UI, Recharts, Lucide. Локальные переменные шрифты Manrope и Unbounded поддерживают кириллицу. Дневник загружается отдельным модулем.
